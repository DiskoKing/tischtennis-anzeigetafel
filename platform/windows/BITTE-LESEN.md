# Windows-USB

Voraussetzungen: Windows 10/11 x64, Edge oder Chrome, beschreibbarer Ordner bzw. USB-Stick. Internet für Live-Daten.

Den kompletten gebauten Ordner entpacken. Nicht direkt aus der ZIP starten. Bildschirm anschließen und Windows mit Win+P auf Erweitern stellen. Starten.cmd doppelklicken. Der erste zusätzliche Bildschirm wird nach seiner Desktopposition gewählt; ohne zusätzlichen Bildschirm wird der Hauptbildschirm genutzt. Beim ersten Start öffnet sich die Konfiguration zusätzlich auf dem Hauptbildschirm.

Einstellungen.cmd öffnet die Konfiguration. Beenden.cmd beendet Server, Reader und die zur Instanz gehörenden Browser. Vor dem Abziehen beenden und Windows Sicher entfernen verwenden. Alt+F4 allein schließt nur das Fenster.

Eigene Daten liegen in app/private und browser-data auf dem Stick. Browser und Betriebssystem können zusätzlich lokale temporäre Daten hinterlassen. Firmenrichtlinien können Programme vom Stick sperren; es werden keine Schutzfunktionen deaktiviert.

Die Bildschirmwahl und Start-/Stop-Logik wurden getestet. Die tatsächliche Vollbildplatzierung muss auf dem Zielrechner überprüft werden. Der Aktualisieren-Knopf folgt später.
